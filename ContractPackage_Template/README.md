# Contract Package Template

このフォルダは、C++ の契約駆動開発で使う配布用パッケージの汎用テンプレートです。

目的は、契約文書と固定公開ヘッダだけを仕様の正本として実装を進められる状態を、題材非依存で素早く作ることです。

## このテンプレートで固定している運用

- 仕様の正本は `contract/` と `include/` のみ
- `tests/` は契約に対応する黒箱受け入れ観点を置く
- 実装詳細は契約対象外とし、実装者に委ねる
- 契約にない振る舞いを足す場合は、先に契約を更新する

## 構成

- `PLACEHOLDERS.md` — 置換すべきプレースホルダ一覧
- `IMPLEMENTATION_BRIEF.md` — 実装者向け作業指示の汎用版
- `CMakeLists.txt` — パッケージ単体でもルート集約配下でも build できる CMake 定義
- `contract/` — 契約文書一式
- `include/` — 固定する公開ヘッダ雛形
- `tests/` — 契約に対応する受け入れテスト雛形

## 使い方

1. このフォルダを対象名で複製する
2. `PLACEHOLDERS.md` のトークンを一括置換する
3. `scripts/New-ContractPackage.ps1` を使う場合、生成先の `README.md` は日本語テンプレートから自動生成される
4. `contract/` を埋めて契約レビューを完了する
5. `include/` の公開ヘッダを凍結する
6. 実装者には、このフォルダだけを渡して `.cpp` を実装させる
7. `tests/` の受け入れ観点で契約適合性を確認する

## 向いているケース

- 公開 API を先に固定したい
- 実装レビューより契約レビューを重視したい
- AI や別担当にブラックボックス実装させたい
- C++ の寿命、無効化、例外方針を事前に固定したい
