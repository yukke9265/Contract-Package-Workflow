# Contract Package — Utf8LineReader

このフォルダは、契約を唯一の仕様根拠として実装を進めるための配布単位です。

実装者に渡す前提は次の通りです。

- 仕様の正本は `contract/` 配下の文書と `include/Utf8LineReader.h` のみ
- 実装の妥当性は `tests/` 配下の受け入れ観点で評価する
- 内部実装、アルゴリズム、バッファ設計は実装者に委ねる
- 契約に書かれていない振る舞いを追加したい場合は、先に契約を変更する

## 構成

- `contract/` — 契約文書一式
- `include/` — 固定された公開ヘッダ
- `tests/` — 契約に対応する受け入れテスト雛形
- `IMPLEMENTATION_BRIEF.md` — 実装者向け作業指示

## 推奨運用

1. 契約レビューを先に完了する
2. `include/Utf8LineReader.h` を凍結する
3. 実装者はこのフォルダだけを根拠に `.cpp` を作成する
4. 受け入れテストを契約に対応づけて実装する
5. 仕様変更が必要になったら実装ではなく契約を先に更新する
