# 契約概要

## 1. 文書情報

- 契約名: Utf8LineReader 契約
- 対象インターフェース: `Utf8LineReader`
- 対象モジュール: textio
- バージョン: 1.0.0
- 作成日: 2026-04-12
- 作成者: GitHub Copilot

## 2. 目的

### 2.1 何を提供するか

`Utf8LineReader` は UTF-8 テキストファイルを 1 行ずつ順次読み取る手段を提供する。
利用者は内部実装を知らなくても、公開メソッドだけでファイルを開き、行を読み、終了状態を判定できる。

### 2.2 なぜ必要か

ファイル全体を一括読み込みせずに順次処理したい用途では、行単位のストリーミング読込が必要になる。
一方で C++ では `std::string_view` の寿命や I/O エラー時の状態が曖昧だと利用側が安全に使えないため、契約として固定する必要がある。

### 2.3 適用範囲

この契約は単一ファイルを先頭から末尾まで読み取る公開 API に適用する。
内部バッファの構成、改行検出アルゴリズム、OS ごとの低レベル I/O 実装は契約対象外とする。

## 3. 責務と非責務

### 3.1 責務

- UTF-8 テキストファイルを open し、行単位に読み出せること
- EOF と I/O エラーを区別して観測可能にすること
- 返却した `std::string_view` の有効期間を明示し、その範囲内では参照可能にすること

### 3.2 非責務

- UTF-8 として不正なバイト列を自動修復すること
- 複数ファイルを同時にマージして読むこと
- 同一インスタンスへの並列アクセスを安全にすること

## 4. C++前提

- 必須言語バージョン: C++20
- 対応コンパイラ: MSVC 19.3x 以降
- 例外方針: 公開 API は例外を投げない
- スレッド安全前提: 単一インスタンスはスレッドセーフではない
- 公開ヘッダ: `Utf8LineReader.h`
