# Contract Package — BoundedQueue

このフォルダは、固定容量の `int` キュー `BoundedQueue` を契約だけで実装させるための配布単位です。

## 想定シナリオ

- 利用者は単一スレッドで、最大要素数が固定された FIFO キューを使いたい
- 公開 API は例外を投げず、状態コードで成功と失敗を返したい
- 実装方式は自由だが、空・満杯・未初期化を観測可能にしたい

## 仕様の正本

- `contract/` — 契約文書一式
- `include/BoundedQueue.h` — 凍結した公開ヘッダ
- `tests/` — 契約に対応する黒箱受け入れ観点

## 実装側に委ねる事項

- 内部リングバッファの実装方式
- メモリ配置と確保方法
- 要素移動の最適化方法

## 実装側が変えてはいけない事項

- `QueueStatus` の公開状態コード
- FIFO 順序
- 未初期化、空、満杯の観測結果
- 例外を投げない公開 API 方針
