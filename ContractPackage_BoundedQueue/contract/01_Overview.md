# 契約概要

## 1. 文書情報

- 契約名: BoundedQueue 契約
- 対象インターフェース: `BoundedQueue`
- 対象モジュール: containers
- バージョン: 0.1.0
- 作成日: 2026-04-12
- 作成者: GitHub Copilot

## 2. 目的

### 2.1 何を提供するか

`BoundedQueue` は固定容量の整数キューを提供し、利用者が FIFO 順序で値を追加・取り出しできるようにする。
利用者は内部実装を知らなくても、公開メソッドだけで初期化、追加、取り出し、状態確認を完結できる。

### 2.2 なぜ必要か

例外を避けたい低レベルコンポーネントでは、失敗を状態コードで扱える固定容量キューが使いやすい。
また、容量超過や未初期化アクセスを未定義動作にせず、明示的に観測できる契約が必要になる。

### 2.3 適用範囲

この契約は `BoundedQueue` の公開 API に適用する。
内部アルゴリズム、内部バッファ、内部キャッシュ、OS 依存の低レベル実装は契約対象外とする。

## 3. 責務と非責務

### 3.1 責務

- 初期化済みの固定容量キューとして `Push` と `Pop` を提供すること
- 空、満杯、未初期化、無効容量を状態コードで区別して返すこと
- 成功時に FIFO 順序を維持すること

### 3.2 非責務

- 複数スレッドからの同時利用を安全にすること
- 容量を自動拡張すること
- `int` 以外の型を扱う汎用テンプレートを提供すること

## 4. C++前提

- 必須言語バージョン: C++20
- 対応コンパイラ: MSVC 19.3x or later
- 例外方針: public API does not throw
- スレッド安全前提: single instance is not thread-safe
- 公開ヘッダ: `BoundedQueue.h`
